### ⚽ Featured Project — Haddaf

My graduation project: an **AI-powered football talent discovery system**. The engine tracks players in match video, extracts pose keypoints frame by frame, and classifies actions — dribble, pass, shoot — returning structured performance data to coaches and scouts.

**Stack:** YOLOv8-Pose · ByteTrack · XGBoost · OpenCV
**Details:** ~1,800 manually annotated images · 11,155 frames cleaned · classifier on 17 normalized skeletal keypoints
